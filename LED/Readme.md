# ESP-IDF LED Blink

## Overview

This is my first ESP-IDF project created to learn ESP32 programming using the ESP-IDF framework.

The program blinks an LED connected to the ESP32 by turning it ON and OFF continuously.

---

## Features

- Blink an LED
- Uses ESP-IDF framework
- Simple GPIO control
- Beginner-friendly project

---

## Hardware Required

- ESP32 Development Board
- LED
- 220Ω Resistor
- Jumper Wires

---

## Software Required

- ESP-IDF
- Visual Studio Code
- Git
